# House Flipper Trainer

Трейнер для **House Flipper (1)** — игры на Unity/Mono. Внешний загрузчик внедряет C#-сборку в процесс игры, после чего внутри игры появляются меню, ESP и инструменты для поиска значений.

> ⚠️ **Только для однопользовательских игр.** Проект сделан в учебных целях (изучение реверс-инжиниринга) и предназначен исключительно для одиночного режима. Не используйте подобные инструменты в онлайн-играх: это нарушает правила игр, портит игру другим людям и ведёт к блокировке аккаунта.

## Функции

1. **ESP.** Рамка вокруг объекта, подпись снизу (например, «Уборка», «Мусор», «Ремонт») и дистанция. Правила задаются шаблоном по имени класса или `go:имя_объекта`. В углу экрана показывается счётчик «Осталось сделать».
2. **Мгновенное выполнение целей.** Для правила ESP можно назначить действие: метод без параметров (например, `Clean`), `Тип.Метод`, `#disable` или `#destroy`. Действие выполняется для всех целей, в радиусе (F4) или автоматически рядом с игроком.
3. **Игрок и мир.** Полёт сквозь стены, множитель скорости ходьбы, поле зрения (FOV), телепорт к ближайшей цели или туда, куда смотрите, слоты позиций, скорость игры (`Time.timeScale`) от x0.1 до x10.
4. **Поиск значений.** Поиск полей по имени во всех объектах игры (деньги, опыт, очки навыков), запись и заморозка значения. Поддерживаются обёртки с `op_Implicit` (например, ObscuredInt).
5. **Инструменты для исследования игры.** Список классов в текущей сцене (кнопка «+ESP»), просмотр полей и методов, вызов метода без параметров, просмотр внутренних данных заданий, дамп всех типов игры в `HFTrainer_dump.txt`.

## Стек

| Часть | Язык | Платформа | Библиотеки / API |
|---|---|---|---|
| Загрузчик (`src/Injector`) | C# | .NET Framework 4.8, WinForms, x64 | WinAPI (`OpenProcess`, `VirtualAllocEx`, `CreateRemoteThread`, `EnumProcessModulesEx`), Mono embedding API |
| Код внутри игры (`src/Payload`) | C# | .NET Framework 3.5 (Mono внутри Unity) | UnityEngine.CoreModule, IMGUIModule, PhysicsModule, TextRenderingModule; System.Reflection |

Сборка: `dotnet` с пакетами `Microsoft.NETFramework.ReferenceAssemblies` и `UnityEngine.Modules` 2021.3.33 (либо DLL из папки установленной игры).

## Как запустить

1. Запустите игру и загрузите сохранение.
2. Запустите `HouseFlipperTrainer.exe` (запрашивает права администратора). Через ~15 с трейнер внедрится автоматически, либо нажмите «Внедрить».
3. В игре:

| Клавиша | Действие |
|---|---|
| Insert / F1 | меню |
| F2 | ESP вкл/выкл |
| F3 | полёт |
| F4 | выполнить цели ESP в радиусе |
| F5 | телепорт к ближайшей цели |
| F6 / F7 | сохранить / загрузить позицию |
| F8 | скорость игры x5 / x1 |
| End | выгрузить трейнер |

Встроенные правила ESP (`Dirt`, `Trash`, `Broken` и др.) — это предположения о названиях классов. Точные классы выбираются во вкладке «Сцена» кнопкой «+ESP». Файлы трейнера создаются в папке игры: `HFTrainer.cfg` (настройки), `HFTrainer.log` (журнал), `HFTrainer_dump.txt` (дамп типов).

Если в папке рядом с `.exe` лежит `HFTrainer.Payload.dll`, загрузчик использует его вместо встроенного.

## Сборка

Нужен .NET SDK 8.

```bat
build.bat "C:\Program Files (x86)\Steam\steamapps\common\House Flipper"
```

С путём к игре payload собирается по её собственным библиотекам Unity, это надёжнее всего. Без аргумента он собирается по эталонным библиотекам из NuGet. Результат: `out\HouseFlipperTrainer.exe`, payload вшит в него как ресурс.

## Структура

```
src/Injector/   MonoInjector.cs — внедрение сборки через mono API (shellcode x64 + CreateRemoteThread)
                MainForm.cs     — окно загрузчика, автовнедрение
src/Payload/    Loader.cs            — точка входа в игре
                TrainerBehaviour.cs  — меню (Unity IMGUI) и горячие клавиши
                Scanner.cs, Esp.cs   — поиск объектов и отрисовка ESP
                Player.cs, Actions.cs, Reflect.cs, Config.cs
build.bat
```
