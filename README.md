# House Flipper Trainer

Внешний трейнер для **House Flipper (1)** (Unity/Mono, x64).
`HouseFlipperTrainer.exe` находит игру и внедряет в неё `HFTrainer.Payload.dll`. Внутри игры payload рисует ESP и меню.

## Быстрый старт
1. Запустите игру и загрузите сохранение.
2. Запустите `release\HouseFlipperTrainer.exe` (он сам попросит права администратора). Через ~15 с трейнер внедрится автоматически, или нажмите «Внедрить».
3. В игре нажмите **Insert** (или **F1**).

Если ничего не происходит, посмотрите `HFTrainer.log` в папке игры.

## Горячие клавиши
| Клавиша | Действие |
|---|---|
| Insert / F1 | меню трейнера |
| F2 | ESP вкл/выкл |
| F3 | полёт / сквозь стены (WASD, Space/E, Ctrl/Q, Shift) |
| F4 | мгновенно выполнить цели ESP в радиусе |
| F5 | телепорт к ближайшей цели |
| F6 / F7 | сохранить / загрузить позицию |
| F8 | скорость игры x5 ↔ x1 |
| End | выгрузить трейнер |

## Вкладки меню
- **ESP**: правила подсветки. Шаблон — часть имени класса или `go:часть_имени_объекта`. Под рамкой выводится подпись («Уборка», «Мусор», «Ремонт») и дистанция. В углу экрана показан счётчик «Осталось сделать». Для каждого правила можно задать **действие** для мгновенного выполнения: метод без параметров (`Clean`), `Тип.Метод`, `#disable` или `#destroy`.
- **Цели**: список всех найденных целей по дистанции. Для каждой есть кнопки «ТП» (телепорт) и «Д» (выполнить). Здесь же авто-выполнение в радиусе.
- **Игрок**: полёт, множитель скорости ходьбы (находит поля `*speed*` у контроллера игрока), FOV, слоты позиций, телепорт туда, куда смотрите.
- **Мир**: скорость игры (Time.timeScale). Ускоряет уборку, покраску, анимации.
- **Поиск значений**: поиск полей по имени во всех объектах игры (`money`, `exp`, `skill`, `point`, `perk` …). Найденное значение можно задать или заморозить. Поддерживаются и обёртки вроде ObscuredInt.
- **Сцена**: какие классы сейчас есть в сцене и сколько их. Кнопка **+ESP** превращает класс в правило ESP. «Инфо» показывает поля и методы класса, а «→ Действие ESP» назначает метод как мгновенное действие. «Дамп» сохраняет все типы игры в `HFTrainer_dump.txt`.
- **Задания**: внутренние данные объектов заданий (Task/Objective/Job/Order …), включая скрытые пункты и счётчики.

## Первая настройка (5 минут)
Встроенные правила (`Dirt`, `Trash`, `Broken` …) составлены по догадке о названиях классов. Точные имена:
1. Возьмите задание и зайдите в дом → меню → **Сцена**, в фильтре наберите `dirt`, `trash`, `clean`, `paint` и т.п.
2. Нажмите **+ESP** у нужных классов, затем во вкладке ESP поменяйте подписи.
3. Для мгновенного выполнения: «Инфо» → найдите метод вроде `Clean`/`Complete`/`Finish` → **→ Действие ESP**. **Сначала сохраните игру.**
4. Настройки сохраняются в `HFTrainer.cfg` в папке игры.

Можно прислать `HFTrainer_dump.txt` разработчику (мне 🙂), и я пропишу точные классы, а заодно «бесконечные деньги» и т.п. одной кнопкой.

## Сборка
Нужен .NET SDK 8. Для сборки под вашу версию Unity (надёжнее всего):
```
build.bat "C:\Program Files (x86)\Steam\steamapps\common\House Flipper"
```
Без аргумента трейнер собирается по эталонным библиотекам Unity из NuGet.

## Структура
- `src/Injector`: WinForms .exe (net48, x64). `MonoInjector.cs` внедряет сборку через mono API: shellcode + CreateRemoteThread.
- `src/Payload`: код внутри игры (net35, совместим с обоими рантаймами Mono). Нужны только CoreModule, IMGUIModule, PhysicsModule и TextRenderingModule.
